## Run Locally

**Prerequisites:**  Node.js

1. Install dependencies:
   `npm install`
2. Set up a portable gcc in the directory if its not already in environment variable path 
3. Set the `GEMINI_API_KEY` in [.env]
4. Add local model gguf within models folder and name it seec-tutor.gguf
3. Run the app:
   `npm run dev`
